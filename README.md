## Mod Bluetooth Xbox Duke

Modification of an original Xbox Duke controller, adding Bluetooth connectivity and modern wireless functionality while preserving its original retro design, controls, and functionality.

The project includes the integration of new electronics, a rechargeable battery, Bluetooth connectivity, rumble control, and custom 3D-printed parts designed to adapt and integrate the components inside the original controller housing.

The result is a wireless version of the classic Xbox Duke controller that can be used with modern computers and gaming systems, combining electronics, firmware development, custom 3D design, and digital fabrication.

Special thanks to:
- [Creality Cloud - Mod Bluetooth Competition Pro XInput](https://www.crealitycloud.com/model-detail/mod-bluetooth-competition-pro-xinput) for sharing and hosting the 3D designs for this project, making the custom parts available to the community.
- LemmingDev and the contributors of [ESP32-BLE-Gamepad](https://github.com/lemmingDev/ESP32-BLE-Gamepad), which provides the Bluetooth gamepad and XInput functionality used in this project.


## Features

- Original Xbox Duke controller housing and controls
- Bluetooth wireless connectivity
- XInput-compatible gamepad functionality
- Rechargeable internal battery
- Wireless operation without the original controller cable
- Integrated rumble/vibration support
- Custom internal mounting system
- Custom 3D-printed parts
- Original buttons, sticks, triggers and D-pad retained
- Firmware-based button and analog input handling
- Compact integration of the electronics inside the original enclosure
- Designed for use with modern computers and compatible gaming systems

## Electronics

The original controller electronics are replaced or adapted with a modern microcontroller-based system capable of handling the controller inputs and communicating wirelessly over Bluetooth.

The electronics integration includes:

- Xiao ESP32 S3 controller hardware
- Bluetooth gamepad communication
- XInput-style controller functionality
- Analog joystick and trigger input handling
- Digital button and D-pad input handling
- Rumble/vibration control
- Rechargeable battery management
- Power regulation and internal wiring
- Custom connections between the original controller controls and the new electronics

The internal components are arranged to make efficient use of the available space inside the original Duke enclosure while keeping the modification serviceable and mechanically secure.

## Battery & Power

A rechargeable battery is integrated into the controller to provide completely wireless operation.

The power system includes the necessary circuitry for:

- Rechargeable battery operation
- Power regulation for the electronics
- Battery charging
- Power distribution to the controller electronics
- Safe integration inside the original controller housing

The objective is to keep the battery and power electronics internally integrated without significantly altering the external appearance of the original Duke controller.

## Compatibility

The controller is designed to operate as a modern Bluetooth gamepad using **XInput-compatible functionality**.

This allows it to be used with compatible modern computers and gaming systems without requiring the original Xbox controller cable or original console interface.

Actual compatibility may depend on the operating system, Bluetooth implementation, game, emulator, or target hardware.

## Project Goals

The main goals of the project are:

1. Preserve the original Xbox Duke design and feel.
2. Convert the controller from wired to wireless operation.
3. Add modern Bluetooth connectivity.
4. Provide XInput-compatible gamepad functionality.
5. Integrate a rechargeable battery inside the original housing.
6. Retain the original controller controls wherever possible.
7. Create a clean and secure internal electronics installation.
8. Use custom 3D-printed components to solve the mechanical integration challenges.
9. Maintain the retro appearance while adding modern functionality.

### Disclaimer

This is a hardware modification project involving the original Xbox Duke controller.

The modification requires disassembly, soldering, wiring, firmware configuration, and installation of custom components.

The exact hardware configuration, components, firmware, battery capacity, and mechanical parts may vary between builds.
